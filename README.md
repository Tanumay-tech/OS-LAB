## 📌 About This Repository

This repository tracks my progress through the Operating Systems lab curriculum. The assignments bridge the gap between application-level programming and hardware management, with a strong focus on:
- **C Programming:** Basic syntax, pointers, memory manipulation, and logic building.
- **System-Level Logic:** Process management, system calls, and resource allocation.
- **Shell Scripting:** Automating tasks and interacting directly with the OS environment via Bash.
